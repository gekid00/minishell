# Minishell

Implémentation d'un shell minimaliste en C.

## 🚀 Démarrage rapide

### Compilation
\`\`\`bash
make
\`\`\`

### Lancement
\`\`\`bash
./program
\`\`\`

## 📚 Fonctionnalités

- Exécution de commandes simples
- Gestion des pipes et redirections
- Variables d'environnement
- Built-in commands

## 🛠️ Commandes

\`\`\`bash
make              # Compiler
make clean        # Nettoyer
make re           # Recompiler
\`\`\`

## 🔧 Technologies

- C
- Makefile
